# 🧰 나의 업무 도구 모음

**바이브 코딩(AI에게 말로 설명해서 코드 만들기)으로 만든 업무용 웹 도구 모음**

복잡한 프로그램 설치 없이 웹 브라우저에서 간편하게 사용할 수 있는 업무 도구들입니다.

### 🌐 사이트 바로가기

👉 **[나의 업무 도구 모음 열기](https://basebeauty.github.io/my-work-tools/index.html)**


## 🛠️ 제공 도구

| 도구 | 설명 | 바로가기 |
|---|---|---|
| 📄 PDF 병합·분할기 | 여러 PDF를 합치고, 필요한 페이지만 나눠요 | [열기](pdf-tool.html) |
| 🍱 점심 메뉴 룰렛 | 날씨까지 반영해서 오늘 점심을 정해 드려요 | [열기](lunch.html) |
| 🛡️ 개인정보 마스킹기 | 문서 속 전화번호·주민번호를 자동으로 가려요 | [열기](masking.html) |
| 🏷️ QR 설비 라벨 생성기 | 설비 목록으로 인쇄용 QR 라벨을 만들어요 | [열기](qr-label.html) |

## 🔒 개인정보 보호

- 입력한 파일과 데이터는 브라우저 안에서 처리합니다.
- 업무 문서를 서버에 업로드하지 않도록 설계했습니다.
- 민감한 업무 자료는 사용 전 각 도구의 처리 방식을 확인하세요.

## 💻 사용한 기술

- **프론트엔드:** HTML, CSS, JavaScript
- **PDF 처리:** pdf-lib, pdf.js
- **QR 코드 생성:** qrcode.js
- **날씨 데이터:** Open-Meteo API

## 🤖 만든 방법

**Claude와 Gemini를 활용한 바이브 코딩**

프로그래밍 코드를 직접 작성하기보다 AI에게 필요한 기능을 자연어로 설명하고, 생성된 결과를 테스트하고 수정하면서 제작했습니다.
